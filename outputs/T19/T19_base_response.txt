Use `total_deaths_per_million` rather than `total_deaths` so countries of different population sizes can be compared more fairly. The code below uses each country's latest available observation, excludes regional aggregates, and plots GDP per capita against COVID-19 deaths per million people.

```
import pandas as pdimport matplotlib.pyplot as pltimport numpy as np# 1. Load the datasetdf = pd.read_csv("owid-covid-data.csv", parse_dates=["date"])# 2. Keep individual countries and exclude regional aggregatescountries = df[    df["continent"].notna()    & ~df["iso_code"].str.startswith("OWID_", na=False)].copy()# 3. Keep rows with both GDP and COVID-19 death datacountries = countries.dropna(    subset=["gdp_per_capita", "total_deaths_per_million"])# Exclude invalid GDP valuescountries = countries[countries["gdp_per_capita"] > 0]# 4. Select the latest available observation for each countrylatest = (    countries.sort_values("date")    .groupby(["iso_code", "location"], group_keys=False)    .tail(1)    .copy())# 5. Calculate the correlation between log GDP and deaths per millionlog_gdp = np.log10(latest["gdp_per_capita"])correlation = log_gdp.corr(latest["total_deaths_per_million"])# 6. Create the scatter plotplt.figure(figsize=(11, 7))plt.scatter(    latest["gdp_per_capita"],    latest["total_deaths_per_million"],    alpha=0.7,    s=45)# Use a logarithmic x-axis because GDP varies substantially# between countriesplt.xscale("log")plt.xlabel("GDP per capita (international dollars)")plt.ylabel("Cumulative COVID-19 deaths per million people")plt.title("Did Richer Countries Handle COVID-19 Better?")plt.text(    0.05,    0.95,    f"Correlation (log GDP vs. deaths per million): {correlation:.2f}",    transform=plt.gca().transAxes,    verticalalignment="top")plt.grid(True, alpha=0.25)plt.tight_layout()plt.show()
```

### How to interpret the chart

- Downward trend: Richer countries tended to have fewer deaths per million, which could suggest better outcomes.
- Upward trend: Richer countries tended to have more deaths per million.
- No clear trend: GDP per capita alone may not explain differences in COVID-19 mortality.

The correlation measures the strength and direction of the relationship in the plotted data. It does not establish that wealth caused better or worse outcomes. Factors such as population age, healthcare capacity, reporting quality, and the timing of the pandemic can also influence recorded deaths.
