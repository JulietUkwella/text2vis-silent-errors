The best way to answer this question is to rank countries by cumulative excess mortality as a percentage above expected deaths. This helps compare countries of different population sizes.

The code below uses `pandas` to load `owid-covid-data.csv`, selects each country's latest available observation, identifies the 15 highest-ranking countries, and plots a horizontal bar chart with `matplotlib`.

```
import pandas as pdimport matplotlib.pyplot as plt# 1. Load the COVID-19 datasetdf = pd.read_csv("owid-covid-data.csv", parse_dates=["date"])# 2. Select the metric for cumulative excess mortality (%)metric = "excess_mortality_cumulative"# Keep country-level records, excluding regional and global aggregatescountries = df.loc[    df["continent"].notna(),    ["location", "date", metric]].copy()# Ensure the mortality values are numericcountries[metric] = pd.to_numeric(    countries[metric], errors="coerce")# Remove rows without a valid date or excess mortality valuecountries = countries.dropna(subset=["date", metric])# 3. Get each country's latest available observationlatest = (    countries    .sort_values("date")    .drop_duplicates(subset="location", keep="last"))# 4. Select the 15 countries with the highest excess mortalitytop_countries = (    latest.nlargest(15, metric)    .sort_values(metric, ascending=True))# 5. Create a horizontal bar chartfig, ax = plt.subplots(figsize=(11, 7))bars = ax.barh(    top_countries["location"],    top_countries[metric])# Add chart title and axis labelsax.set_title(    "Countries with the Highest Cumulative Excess Mortality",    fontsize=15,    pad=15)ax.set_xlabel("Cumulative excess mortality (% above expected deaths)")ax.set_ylabel("Country")# Display the values beside the barsax.bar_label(bars, fmt="%.1f%%", padding=4)# Improve readabilityax.grid(axis="x", linestyle="--", alpha=0.4)ax.set_axisbelow(True)ax.set_xlim(right=max(0, top_countries[metric].max()) * 1.15)plt.tight_layout()plt.show()
```

### How to interpret the chart

Each bar represents a country’s cumulative excess mortality in its latest available observation. Countries with longer bars experienced a greater percentage of deaths above the expected level.

Important distinction: Excess mortality can also be measured by the number of excess deaths per million people or the total number of excess deaths. To rank countries by excess deaths per million instead, change the metric to:

```
metric = "excess_mortality_cumulative_per_million"
```

For that alternative, change the x-axis label to `"Cumulative excess deaths per million people"` and use `ax.bar_label(bars, fmt="%.0f", padding=4)` to label the bars.

The actual country rankings will appear when you run the code against your CSV file. Because countries have different latest reporting dates, the chart may compare observations from different points in time.
