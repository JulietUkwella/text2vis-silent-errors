# Analytical choices before writing the code

The question “Which countries were hit hardest by COVID-19 deaths?” has several possible interpretations. The chart will use cumulative reported deaths to identify the 10 countries with the highest death toll, while making clear that this measures absolute deaths, not the risk of death for an individual.

| Analytical choice                               | Option selected                                       | Reason                                                                                                                                                                                                                                                                               |
| ----------------------------------------------- | ----------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 1. Measure of deaths                            | `total_deaths`                                        | Measures cumulative reported deaths, making it appropriate for ranking the overall death toll. `new_deaths` captures daily deaths, while `new_deaths_smoothed` is better for comparing trends over time.                                                                             |
| 2. Absolute totals or population-adjusted rates | Absolute deaths                                       | Directly answers which countries had the most deaths overall. A separate analysis using `total_deaths_per_million` would better compare the impact relative to population size.                                                                                                      |
| 3. Time period                                  | All dates available in the CSV                        | Uses the full available history rather than arbitrarily selecting a year or wave. The results will depend on the dataset's last recorded date.                                                                                                                                       |
| 4. Rows to include                              | Country-level rows only                               | Excludes regional and global aggregates, such as `World`, `Europe`, and `High income`, which could otherwise dominate the ranking. For this dataset, rows with a three-letter `iso_code` that does not start with `OWID_` are a practical starting filter for country-level entries. |
| 5. Which date to use for each country           | The latest valid observation for each country         | Avoids adding cumulative totals across dates, which would count the same deaths repeatedly. It also captures each country's most recent reported total.                                                                                                                              |
| 6. Missing or invalid values                    | Ignore missing, nonnumeric, and negative death totals | Prevents invalid values from affecting the ranking. Countries without a valid cumulative death total will not be ranked.                                                                                                                                                             |
| 7. Duplicate records                            | Keep the last row for each country-date combination   | The data is expected to have one row per location per date, but checking for duplicates helps prevent a duplicate observation from being selected accidentally.                                                                                                                      |
| 8. Ranking and chart type                       | Top 10, horizontal bar chart                          | A horizontal bar chart makes country names readable and clearly compares the 10 largest cumulative totals. The ranking will be in descending order.                                                                                                                                  |

## What could make the chart misleading?

- Population size: Countries with larger populations can have higher death totals even when their death rates are lower. The chart does not show deaths per million people.
- Underreporting and differences in definitions: Countries differ in how deaths were tested, classified, and reported. Reported totals are not necessarily comparable estimates of all deaths caused by the pandemic.
- Different reporting dates: The most recent valid observation may be from different dates in different countries. The code will display each country's observation date so this limitation is visible.
- Countries versus territories: The dataset contains some territories and other special locations as well as sovereign countries. Filtering on a nonmissing `continent` excludes most regional and global aggregates, but does not guarantee that every remaining location is a sovereign country.
- Historical revisions and missing data: Cumulative death figures can be revised, and some countries have gaps in their reporting. Using the latest valid reported total avoids counting the same deaths repeatedly, but it does not eliminate these data-quality issues.

## Python code

### How to interpret the result

The chart answers: Which 10 country-level locations have the highest cumulative reported COVID-19 death totals in the available data?

It intentionally compares absolute death counts, not deaths per capita. For a more balanced assessment of which countries were hit hardest relative to their population, repeat the analysis using `total_deaths_per_million` instead of `total_deaths`. That would answer a different but equally important question: where was the reported death toll highest relative to population size?
