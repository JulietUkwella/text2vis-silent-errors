The code below uses `pandas` to load `owid-covid-data.csv`, finds the latest available cumulative COVID-19 deaths per million for each country, and uses `matplotlib` to create a sorted horizontal bar chart.

```
import pandas as pdimport matplotlib.pyplot as plt# 1. Load the datasetdf = pd.read_csv("owid-covid-data.csv", parse_dates=["date"])# 2. Keep country rows and exclude aggregate locationscountries = df[    df["continent"].notna()    & ~df["iso_code"].astype(str).str.startswith("OWID_")].copy()# 3. Ensure the death-rate column is numericcountries["total_deaths_per_million"] = pd.to_numeric(    countries["total_deaths_per_million"], errors="coerce")# 4. Remove rows where the death-rate value is missingcountries = countries.dropna(subset=["total_deaths_per_million"])# 5. Get each country's latest available observationlatest = (    countries.sort_values("date")    .groupby("location", as_index=False)    .tail(1)    .sort_values("total_deaths_per_million"))# 6. Create a horizontal bar chartfig, ax = plt.subplots(    figsize=(12, max(8, len(latest) * 0.25)))ax.barh(    latest["location"],    latest["total_deaths_per_million"])ax.set_title(    "Latest Cumulative COVID-19 Deaths per Million by Country",    fontsize=15)ax.set_xlabel("Total COVID-19 deaths per million people")ax.set_ylabel("Country")ax.grid(axis="x", linestyle="--", alpha=0.5)ax.set_axisbelow(True)plt.tight_layout()plt.savefig(    "latest_covid_death_rate_per_million.png",    dpi=200,    bbox_inches="tight")plt.show()
```

How it works: The code excludes aggregate locations such as the world total, selects each country's most recent observation with a reported death figure, and sorts the bars from lowest to highest.

Note: This chart uses `total_deaths_per_million`, which measures cumulative deaths per million people. The latest reporting date may differ by country. If you instead want the most recently reported daily death rate per million, replace `total_deaths_per_million` with `new_deaths_per_million` throughout the code.
