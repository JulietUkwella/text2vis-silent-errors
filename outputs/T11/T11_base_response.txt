The code below uses pandas to load `owid-covid-data.csv` and matplotlib to create a grouped bar chart comparing vaccination rates across the seven G7 countries. It shows both the percentage of the population that received at least one dose and the percentage that is fully vaccinated, using the latest available data for each country.

```
import pandas as pdimport matplotlib.pyplot as plt# Load the COVID-19 datasetdf = pd.read_csv("owid-covid-data.csv", parse_dates=["date"])# List of G7 countriesg7_countries = [    "Canada",    "France",    "Germany",    "Italy",    "Japan",    "United Kingdom",    "United States"]# Vaccination metrics and their chart labelsvaccination_metrics = {    "people_vaccinated_per_hundred": "At least one dose",    "people_fully_vaccinated_per_hundred": "Fully vaccinated"}# Filter the data to include only G7 countriesg7_data = df[df["location"].isin(g7_countries)]# Get the latest available non-missing value for each country and metriclatest_records = []for country in g7_countries:    country_data = g7_data[g7_data["location"] == country]    for column, label in vaccination_metrics.items():        available = country_data[["date", column]].dropna(subset=[column])        if not available.empty:            latest = available.loc[available["date"].idxmax()]            latest_records.append({                "Country": country,                "Vaccination status": label,                "Percentage": latest[column],                "Date": latest["date"]            })# Convert the results to a DataFramelatest_df = pd.DataFrame(latest_records)# Arrange the data for plottingchart_data = latest_df.pivot(    index="Country",    columns="Vaccination status",    values="Percentage")chart_data = chart_data.reindex(g7_countries)chart_data = chart_data.reindex(    columns=["At least one dose", "Fully vaccinated"])# Create the grouped bar chartax = chart_data.plot(    kind="bar",    figsize=(12, 6),    width=0.8)ax.set_title("COVID-19 Vaccination Rates in G7 Countries")ax.set_xlabel("Country")ax.set_ylabel("Population vaccinated (%)")ax.set_ylim(0, 100)ax.legend(title="Vaccination status")ax.tick_params(axis="x", rotation=30)plt.tight_layout()plt.show()# Print values and the dates they were reportedprint(    latest_df.sort_values(["Country", "Vaccination status"])    .to_string(index=False))
```

### How to interpret the chart

- At least one dose: Uses `people_vaccinated_per_hundred`.
- Fully vaccinated: Uses `people_fully_vaccinated_per_hundred`.
- Latest available data: Each country and vaccination measure uses its most recent non-missing observation, so reporting dates may differ.

The chart lets you compare vaccination coverage in Canada, France, Germany, Italy, Japan, the United Kingdom, and the United States. The exact percentages will be calculated from your local CSV file when you run the code.
