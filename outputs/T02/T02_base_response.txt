A good way to compare how badly COVID-19 affected South American countries is to create a horizontal bar chart of cumulative COVID-19 deaths per million people. This measure accounts for differences in population size, making countries easier to compare fairly.

The following Python code uses `pandas` to load and prepare the CSV file and `matplotlib` to create the chart.

```

```

### How to interpret the chart

- Longer bars indicate more reported cumulative COVID-19 deaths per million people.
- Shorter bars indicate fewer reported cumulative deaths per million people.
- Countries are ranked from lowest to highest, making differences easy to see.

This chart uses `total_deaths_per_million` rather than raw death counts, so more populous countries are not automatically ranked as more severely affected. It measures reported cumulative mortality, not the full impact of COVID-19, and differences in testing and death reporting can affect comparisons.
